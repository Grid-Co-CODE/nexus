Conferência das ligações. Uma vez por dia o Nexus relê o que está gravado no banco e confere, tabela a tabela, se cada ID (data, usina, equipe, pessoa, equipamento) existe na dimensão dele e se a chave de cada fato se repete. O ID órfão é a linha que aponta para algo que a dimensão não tem; a chave repetida, a mesma linha gravada duas vezes. Os dois têm de dar zero. ID vazio não é órfão: é o que não ligou, e aparece na qualidade de cada tabela.
