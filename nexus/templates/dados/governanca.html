{% if ver == 'organograma' %}{% include "dados/_organograma_explica.html" %}{% else %}{% call explica('O que é a matriz') %}

Cada acontecimento (um fato: um fechamento, uma ronda, a geração de um dia) ligado aos cadastros de referência (as dimensões: usina, pessoa, data…) por ID. Quando dois setores usam a mesma dimensão pelo mesmo ID, os dados deles se cruzam sem conversão. A matriz vem do catálogo do Nexus (nexus/dados/catalogo.py); a qualidade, da carga de hora em hora.

Como ler. Cada linha é um fato; cada coluna, uma dimensão. A marca diz por onde o fato liga: ID do cadastro (o certo), código de um sistema (pelo de-para), pessoa (o código do e-mail, com a chave), nome (texto livre: junção frágil), colunas (um equipamento por coluna) ou cadastro próprio; o ponto é "não tem". No fato já gravado com os IDs, o número é quanto dele ligou no banco. Clique no fato para ver o livro, o grão, as medidas e a qualidade da ligação.

Tipo do fato. Transação (1 linha por acontecimento, não muda), foto periódica (o estado no fim de cada dia ou semana), foto acumulada (a linha muda até fechar, como a PT aguardando e depois decidida), sem medida (só registra que aconteceu).
