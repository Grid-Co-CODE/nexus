{% call explica('O que é este arquivo e como ele sobe') %}

O que é. O mapa de ruas, rodovias, cidades e rios do Brasil que o Mapa de equipe desenha. É nosso: o Nexus o serve a quem entrou, e nenhum serviço de mapa de terceiro vê a região que alguém está olhando.

De onde vem. Os dados do OpenStreetMap, no esquema do Protomaps, recortados só no Brasil pela ferramenta ferramentas/mapa_base_brasil.py (até o zoom 14, ~2,4 GB). A ferramenta imprime o SHA-256 do arquivo: cole-o aqui para o servidor conferir o arquivo inteiro.

Como sobe. Em partes de {{ parte_max // 1024 // 1024 }} MB, cada uma conferida pela assinatura dela. Se a conexão cair, escolha o mesmo arquivo de novo: a subida continua de onde parou. O que está no ar só é trocado quando o arquivo inteiro confere; enquanto não há arquivo, o Mapa de equipe usa o desenho dos estados.
