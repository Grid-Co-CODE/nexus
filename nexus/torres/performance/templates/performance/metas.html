{% call explica('Como funciona', termos=True) %} {{ termo('Para que serve') }}
A meta de cada mês das usinas que não são da Thopen (a Thopen manda a própria meta, que já está no banco): a energia esperada (P50, P90, P75), o PR e a irradiação prevista.
{{ termo('Três jeitos') }}
Anexar o PDF do PVsyst (a tabela “Balances and main results” preenche os 12 meses), digitar, ou colar do Excel: copie as células lá e cole numa célula daqui, que as outras se preenchem para a direita e para baixo.
{{ termo('Como se conta') }}
Pelo PVsyst: P50 = E_Grid; P90 = P50 × (P90 ÷ P50 do ano); P75 = P50 − (P50 − P90) × 0,6745 ÷ 1,2816; PR = o do mês; IPOA = GlobInc; GHI = GlobHor. É o ano 1 do PVsyst, sem degradação.
{{ termo('Em cinza') }}
A meta que está hoje na aba Info Mensal do BD_Performance, para comparar. É meta, não o realizado.
{{ termo('Edições') }}
Cada Salvar fica registrado: quem, quando, de onde veio (PVsyst, PVsyst editado ou manual) e cada valor que mudou, de quanto para quanto.
{{ termo('Protótipo', 'alerta') }}
Salva no Nexus. A Sala de controle e o Gerencial seguem com a Info Mensal até a validação.
