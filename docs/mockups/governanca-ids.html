Toda planilha com ID e ligação

Hoje cada base tem a sua lista de usinas e elas se ligam pelo nome. Onde existe coluna Código, a ligação é de 99%; pelo nome, de 44% a 87%. Solução (decidida em 04/10): cada cadastro tem ID numérico e a ligação é por ID; o código e os nomes de cada sistema ficam na tabela de_para. O cadastro do Nexus é a fonte, e nenhuma base entra sem o ID.

1Toda tabela tem ID

Primeira coluna, nunca reaproveitado, nunca editado.

2Ligação guarda o ID

Linha que fala de usina, equipe ou pessoa guarda o ID dela, não só o nome.

3Sem chave, não entra

Base nova ou coluna nova só entra com a chave. O Nexus recusa e diz o que falta.
